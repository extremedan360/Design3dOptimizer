# Biblioteca Blender, Unity y animación

Documentación aportada por el usuario y leída íntegramente el 12 de noviembre de 2026: **46 entradas en tres ZIP, 34 documentos únicos y 12 duplicados exactos**. Contiene apuntes breves y enlaces, no copias completas de los manuales oficiales ni los cursos.

Los originales se conservan sin modificaciones en `originals/`. [manifest.json](manifest.json) registra cada archivo, tamaño, SHA-256, origen y ubicación canónica. [links.json](links.json) contiene **33 URLs únicas**; no se cuenta como lectura de una web el mero hecho de catalogar su enlace.

## Procedencia y permisos

Los ZIP fueron aportados para incorporarlos a este agente. Sus índices describen guías originales gratuitas y enlaces públicos; el segundo y tercero permiten usarlas como apuntes. No se asigna una nueva licencia a manuales externos por enlazarlos, ni se redistribuyen esos sitios, cursos, modelos o recursos.

Las síntesis del agente y el código original del repositorio usan la licencia raíz. Los textos aportados conservan sus indicaciones originales. Si se sustituye o amplía una fuente, revisar su licencia y conservar procedencia.
