# Checklist de aceptación de asset

- [ ] Silueta y escala verificadas
- [ ] Triángulos justificados según presupuesto del proyecto
- [ ] Normales y sombreado correctos
- [ ] UV sin distorsión relevante
- [ ] Texturas presentes y comprimidas para plataforma
- [ ] Materiales y shaders compatibles
- [ ] Pivote, orientación y nombres correctos
- [ ] LOD cuando sea beneficioso
- [ ] Colliders adecuados
- [ ] Rig/animaciones probados si aplica
- [ ] Importación en Unity validada
- [ ] Rendimiento medido en escena representativa
