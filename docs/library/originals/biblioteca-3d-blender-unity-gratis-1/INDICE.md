# Biblioteca gratuita Blender + Unity

Selección revisada el 12 de noviembre de 2026.

**Contenido:** 7 manuales originales en español y 19 recursos externos clasificados, todos con acceso gratuito a la página indicada. No se han descargado manuales completos de terceros. Algunas páginas pueden cambiar, pedir registro gratuito o limitar contenido adicional.

**Para descargar el manual oficial completo de Blender:** abre https://docs.blender.org/manual/en/latest/ y elige «Download the manual as web pages (HTML)» o «EPUB».

**Orden recomendado:** fundamentos → UV → LOD → personajes → exportación → perfilado → automatización.
