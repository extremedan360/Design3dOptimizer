# Checklist de entrega de animación para videojuegos

- [ ] Modelo y rig con nombres consistentes.
- [ ] Jerarquía de huesos limpia y deformaciones verificadas.
- [ ] Peso de vértices revisado.
- [ ] Pose de referencia documentada.
- [ ] Acciones separadas y clips con duración correcta.
- [ ] Loops sin saltos visibles.
- [ ] Sin foot sliding excesivo en Unity.
- [ ] Escala, ejes y pivotes correctos.
- [ ] Exportación FBX probada.
- [ ] Avatar Humanoid o Generic configurado.
- [ ] Animator Controller y Blend Trees probados.
- [ ] Root Motion configurado conscientemente.
- [ ] IK/constraints probados en runtime.
- [ ] Coste de animación medido con Profiler.
- [ ] Archivos fuente y licencias de recursos identificados.
