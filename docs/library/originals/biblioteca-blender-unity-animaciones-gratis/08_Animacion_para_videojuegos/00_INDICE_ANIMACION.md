# Biblioteca de animación para videojuegos — Blender + Unity

Todo el contenido de esta carpeta es original y gratuito. Los enlaces remiten a documentación pública; **no se incluyen copias completas de manuales externos**.

## Ruta recomendada
1. Rigging y skinning en Blender.
2. Animación de acciones y ciclos para juegos.
3. NLA y biblioteca de acciones.
4. Exportación FBX y pruebas de importación en Unity.
5. Mecanim: Avatar, Animator Controller, estados y transiciones.
6. Blend Trees, Root Motion e IK.
7. Optimización y pruebas con Profiler.
8. Automatización mediante Blender Python.
