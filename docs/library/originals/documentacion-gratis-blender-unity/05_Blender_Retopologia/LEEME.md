# 05 Blender Retopologia

**Recurso público gratuito:** https://docs.blender.org/manual/en/latest/modeling/meshes/retopology.html

## Contenido
Retopología y flujo de geometría.

## Ejercicio recomendado
Reduce una escultura a una malla deformable y comprueba silueta y loops.

## Criterios de calidad
- Comprobar geometría y caras duplicadas.
- Revisar normales, UV, escala y pivote.
- Verificar materiales y compresión de texturas.
- Evaluar rendimiento en la plataforma objetivo.
