# 02 Blender Fundamentals Gratis

**Recurso público gratuito:** https://studio.blender.org/training/blender-2-8-fundamentals/chapter/modeling/

## Contenido
Herramientas esenciales de modelado; lecciones marcadas Free.

## Ejercicio recomendado
Practica extrude, loop cut, bevel y knife sobre un objeto de escenario.

## Criterios de calidad
- Comprobar geometría y caras duplicadas.
- Revisar normales, UV, escala y pivote.
- Verificar materiales y compresión de texturas.
- Evaluar rendimiento en la plataforma objetivo.
