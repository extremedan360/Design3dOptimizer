# 03 Unity LOD

**Recurso público gratuito:** https://docs.unity3d.com/Manual/LevelOfDetail.html

## Contenido
Grupos LOD y transición entre mallas.

## Ejercicio recomendado
Crea tres variantes de un árbol y configura LOD Group; mide triángulos visibles.

## Criterios de calidad
- Comprobar geometría y caras duplicadas.
- Revisar normales, UV, escala y pivote.
- Verificar materiales y compresión de texturas.
- Evaluar rendimiento en la plataforma objetivo.
