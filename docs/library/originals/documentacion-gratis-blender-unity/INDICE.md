# Biblioteca gratuita Blender + Unity

Seis recursos públicos sin cursos de pago. Las carpetas incluyen guías originales y enlaces a documentación gratuita, no copias completas de las páginas web. Algunos recursos requieren conexión a Internet.

1. **01_Blender_Manual** — https://docs.blender.org/manual/en/latest/
2. **02_Blender_Fundamentals_Gratis** — https://studio.blender.org/training/blender-2-8-fundamentals/chapter/modeling/
3. **03_Unity_LOD** — https://docs.unity3d.com/Manual/LevelOfDetail.html
4. **04_Unity_Optimizacion_Arte_3D** — https://learn.unity.com/course/3d-art-optimization-for-mobile-gaming-5474
5. **05_Blender_Retopologia** — https://docs.blender.org/manual/en/latest/modeling/meshes/retopology.html
6. **06_Unity_Profiler** — https://docs.unity3d.com/Manual/Profiler.html

El manual oficial de Blender ofrece descargas HTML y EPUB para consulta sin conexión desde su portada.
